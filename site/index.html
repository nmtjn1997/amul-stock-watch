Amul Stock Watch Install FAQ GitHub

Know the moment it is back in stock.

Popular Amul products, like the high protein lassi, sell out within minutes and stock differs by pincode. Amul Stock Watch checks the products you care about at every pincode you care about, about once a minute, and tells the right people the moment something comes back.

Use it now, free Try the demo Install your own View on GitHub

Free and open source. Use the hosted version, or run your own copy. No Amul account needed.

What it does

Per pincode, per person

"Tell me and my sister about Rose Lassi in Bangalore, and Dad only about Buttermilk in Delhi." Each of those is one watch.

Alerts once per restock

One message when a product goes from out of stock to in stock. Nothing while it stays in stock. Selling out re-arms it.

Straight to your phone

Push through the free ntfy app, Telegram, email, Slack, Discord or any webhook. Tap the alert to open the product.

No login, no cookies

It keeps its own anonymous shop session and renews it by itself. It never logs in, adds to cart or places orders.

A web UI that works on phones

Add watches, people and products, see live stock, send test alerts, read logs. Or edit two commented YAML files.

Runs anywhere

macOS, Linux, Windows or Docker. One process, one SQLite file, starts at login with one command.

How it works

Add a watch

A pincode, the products to check there, and who to tell.

It checks quietly

Requests are spread across each minute, gentle on the shop. It remembers what it last saw.

You get one message

The moment a product flips to in stock at a watched pincode, each person on that watch is told once.

Install

curl -fsSL https://raw.githubusercontent.com/nmtjn1997/amul-stock-watch/main/scripts/install.sh | bash
amul-watch serve

Needs Python 3.10+, curl and git (on Debian and Ubuntu also python3-venv). Then open http://127.0.0.1:8847.

irm https://raw.githubusercontent.com/nmtjn1997/amul-stock-watch/main/scripts/install.ps1 | iex

Then open a new PowerShell window and run amul-watch serve. Needs Python 3.10+ and git.

git clone https://github.com/nmtjn1997/amul-stock-watch.git
cd amul-stock-watch
docker compose up -d --build

Then open http://127.0.0.1:8847 and add an ntfy or Telegram notifier first: desktop alerts cannot leave a container.

Questions

Do I need an Amul account, a token or a cookie?

No. It reads the same public product data the shop's own page loads. Tokens only come in for some ways of sending alerts, like a Telegram bot.

Where does it run?

Two options. The hosted version runs on Cloudflare: sign up, add up to 10 alerts, done. Or run your own copy on a laptop, a home server or in Docker, with no limits. The demo on this site is the self-hosted screen with sample data.

Can I use it from my phone?

Yes. Alerts arrive on your phone through ntfy, Telegram or email. To manage watches from the phone too, let the UI listen on your Wi-Fi with a password; the README shows the two lines to add.

Is it official?

No. It is an unofficial personal project, not affiliated with Amul or GCMMF. It polls politely and never buys anything.
